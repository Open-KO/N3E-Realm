# Gap register

This is the one place that lists what n3e does not do yet, or does differently from
its references. It was created 2026-09-25 when the numbered phases and phase-spec
files were dropped ([ROADMAP](ROADMAP.md)).

Status values:

- **open**: not started.
- **partial**: some support exists.
- **absent**: a KO feature with no n3e counterpart.
- **deviation**: a documented deliberate difference.

The KO feature catalog (FEATURES, 81 records) and
PARITY keep per-record binary evidence. This register summarizes them
and adds engine gaps that have no KO record. Update it whenever a gap closes or opens
(AGENTS.md). The parity loop works through these rows in the order
of its queue; `tools/parity/queue.py check` fails when an open
row here has no queue item. Closed items move to the [closed list](#recently-closed) with their
decision.
